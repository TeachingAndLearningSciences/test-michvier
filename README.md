# Exercise 2: Variables

Create 4 different variables.
Variable *a* should have the value 7, variable *b* should have the value 9.2, variable *c* should be 'c', and variable *d* should have the value 'Hi'.

Print the values of all variables to the console.

## Example Output

```
a = 7
b = 9.2
c = c
d = Hi
```

# Exercise 3: Discount Calculator

Write a program that calculates a discount for a purchase. To do this, create variables that contains the price of a product (*price*), the amount of purchased products (*amount*) and the discount that should be applied (*discount*).

Calculate the pre-discount price (product of price and amount), the discount and the final price and print all 3 values to the console.

## Example Output (for 6 euros, 10 pieces and a discount of 10%)

```
Pre-discount price: 60
Discount: 6.0
Final price: 54.0
```

# Exercise 4: Soccer Salary

Create a program that calculates the salary for a professional soccer player. A player receives a base compensation and a premium per goal scored. Calculate the salary by creating variables for the base compensation (*base_pay*), the premium per goal (*premium*) and the amount of goals scored (*amount*). Then add the base compensation to the product of the premium per goal times the amount of goals and print the result.

## Example Output (for 400000 base compensation, 25000 premium and 8 goals)

```
Salary: 600000
```

# Exercise 5: Price Calculation Painter

The company Fresh Brush charges the following rates for painting rooms:

 - **Walls:** Walls are painted with orange paint, at a price of 10.0 euro per litre.
 - **Ceilings:** Ceilings are painted with white paint, at a price of 12.5 euro per litre.
 - **Service:** For the painting, Fresh Brush charges a rate of 22.5 euro per hour.

These prices exclude 20% VAT, which needs to be added to the final price. 

Create an offer for the customer. Create variables for the customers name (*name*) and address (*address*), as well as the amount of paint needed for the walls (*orange*) and ceilings (*white*) respectively, and the amount of hours that need to be paid (*hours*).

Create the necessary variables (*orange*, *white*, *hours*, *name*, *address*), perform the calculations and print the corresponding offer to the console. You can also create variables for the respective prices, or write the values directly into your code.

## Example Output (for customer name 'John Doe', address 'Altenbergerstrasse 69', 5 litre orange paint, 3 litre white paint and 6 hours of painting)

```
Addressee: John Doe Altenbergerstrasse 69

We can make the following offer:
Paint Price: 87.5 EUR
Service Charge: 135.0 EUR
Total - excl. VAT: 222.5 EUR
Gross Total: 267.0 EUR
```
